# Atualização - Encaminhamentos dentro do Envio periódicos

- Ajustado o nome visual do módulo de "ENVIO PERIÓDICOS" para "Envio periódicos".
- Adicionado botão "Gerar encaminhamentos" ao lado de "Planilha para encaminhamentos" dentro da competência.
- O botão abre um popup para enviar a planilha base preenchida e escolher PDF ou Word.
- A geração reaproveita a rotina de Encaminhamentos do site principal, entregando `encaminhamentos.zip` com um ZIP por CNPJ.
- A função antiga de Encaminhamentos permanece disponível como fallback.
