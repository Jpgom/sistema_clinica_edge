# Atualização - Reorganização visual Clínica / Interno

## O que foi ajustado

1. Removidas da navegação e da página inicial as funções independentes:
   - Encaminhamentos
   - Complementar laudos

2. A função Encaminhamentos foi mantida apenas como recurso interno do Envio periódicos.
   - O acesso antigo `/encaminhamentos` agora direciona o usuário para o módulo Envio periódicos.

3. Página inicial reorganizada em duas áreas simples:

### Clínica
- Encaminhamento individual
- Enc. complementares
- Laudo PCD
- Físico e Mental
- Atestado Médico

### Interno
- Envio periódicos
- Separar exames
- Exames a Prazo
- Renumerador
- E-SOCIAL
- PGR / SST

4. Menu lateral reorganizado seguindo a mesma estrutura:
   - Clínica
   - Interno
   - Sistema

5. Visual da página inicial ajustado para ficar mais simples, bonito e fácil de usar:
   - Cards maiores e mais claros
   - Menos informações repetidas
   - Destaque apenas para as rotinas principais
   - Botões diretos
   - Layout responsivo para celular
